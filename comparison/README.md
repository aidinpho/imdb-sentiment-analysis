# Model Comparison

This directory is intended to compare the Machine Learning and Deep Learning sentiment analysis models.

## Models

- **Machine Learning:** TF-IDF + Logistic Regression
- **Deep Learning:** Embedding + LSTM (PyTorch)

## Planned Evaluation

The comparison notebook will evaluate both models using:

- Accuracy
- Precision, recall, and F1-score
- Confusion matrices
- Training time
- Inference latency
- Model size

## Fair Comparison

For a meaningful comparison, both models should be evaluated on the same test examples using consistent evaluation procedures.

Results should be calculated from actual model predictions rather than copied or assumed from previous runs.
